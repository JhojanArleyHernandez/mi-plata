# Mi Plata

App personal para llevar gastos, ingresos por quincena, recibos con su frecuencia de pago, tarjeta de crédito, metas de ahorro y hábitos.

- Funciona en el navegador y se puede instalar en el celular (Añadir a la pantalla de inicio).
- Funciona sin internet.
- No usa servidores ni cuentas: los datos se guardan solo en el dispositivo donde se usa. Tiene copia de seguridad (exportar e importar).
